Политика конфиденциальности

Сведения об обработке данных при посещении сайта dayz-mod.ru.

1. Область действия

Политика описывает обработку персональных данных посетителей сайта DayZ Companion (dayz-mod.ru) и пользователей формы обратной связи. Сайт не требует регистрации. Обработка данных непосредственно в приложении Windows не входит в область этого документа.

Оператором персональных данных является физическое лицо — владелец и администратор проекта DayZ Companion и сайта dayz-mod.ru. Для связи с оператором используется форма обратной связи.

2. Посещение сайта

Сайт размещён на GitHub Pages. При посещении хостинг регистрирует IP-адрес в целях безопасности. Подробнее: политика GitHub.

3. Аналитика и cookie

Для анализа посещаемости и улучшения сайта используется Яндекс Метрика (ООО «ЯНДЕКС»), включая Вебвизор и карту кликов. Сервис получает сведения об устройстве и браузере, IP-адресе, посещённых страницах, источниках переходов, действиях и технических идентификаторах. Учитываются переходы к скачиванию, обратной связи и добровольной поддержке; для скачивания передаётся версия сборки. Вебвизор записывает взаимодействия с сайтом; записи доступны в течение 15 дней, включая текущий день. Состав данных Метрики.

Метрика использует cookie и localStorage. Сайт также запоминает закрытие уведомления в localStorage. Кнопка закрытия не отключает аналитику. Настройки браузера позволяют ограничивать и удалять cookie и данные сайтов, а также блокировать загрузку счётчика. Cookie Метрики и условия использования Метрики.

4. Обратная связь

Обращения принимаются через внешнюю Яндекс Форму. Обрабатываются текст обращения, контактные сведения, если они предоставлены, и добровольно приложенные диагностические архивы или скриншоты. Цели — рассмотрение обращений, диагностика ошибок и улучшение приложения. Ответы хранятся в Яндекс Формах; копии обращений могут поступать на электронную почту оператора. Установленный срок хранения обращений и вложений — не более трёх месяцев с даты получения, если иной срок не требуется по закону. Не включайте в обращения пароли, ключи, платёжные реквизиты и чужие персональные данные. Политика Яндекса.

5. Внешние сервисы

Скачивание файлов осуществляется через GitHub Releases, добровольная поддержка — через CloudTips. Сайт не содержит полей для банковских карт: платёжные сведения вводятся на стороне платёжного сервиса. Оригинальные интерактивные карты XAM открываются по внешней ссылке. Внешние сервисы обрабатывают данные по своим правилам: GitHub, CloudTips, Яндекс.

6. Права и обращения

Вы вправе запросить сведения об обработке ваших персональных данных, их уточнение, блокирование или удаление при наличии законных оснований, отозвать согласие, потребовать прекращения обработки и обжаловать действия оператора в Роскомнадзоре или суде. Запрос можно направить через форму обратной связи, указав, что он касается персональных данных.

7. Условия обработки и хранения

Обработка ограничивается данными, необходимыми для указанных целей. По окончании срока хранения или при возникновении иных законных оснований для прекращения обработки персональные данные подлежат удалению либо обезличиванию, включая копии обращений в электронной почте.
