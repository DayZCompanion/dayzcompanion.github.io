Системные требования

  • Windows 10 или 11, 64-разрядная

    Для игровых инструментов нужна установленная игра DayZ.

  • Оконный режим DayZ

    Для полноценной работы всех инструментов используйте оконный режим игры. Безрамочный оконный режим рекомендуется для экранных наложений. В эксклюзивном полноэкранном режиме наложения могут быть скрыты, а захват изображения ограничен.

  • Место на диске

    Для ZIP и распакованных файлов вместе потребуется около 1 ГБ. Для обновления оставьте дополнительное свободное место.

  • Захват радио

    Для изолированного захвата звука DayZ нужен Windows build 20348 или новее. На Windows 10 22H2 (19045) совместимость проверяется при запуске прослушивания.

Первый запуск

  1. Скачайте ZIP

    Нажмите «Скачать ZIP» в начале страницы.

  2. Распакуйте архив

    Извлеките все файлы в отдельную папку.

  3. Запустите DayZCompanion.exe

    Откройте файл в распакованной папке.

Обновление

  1. Проверьте обновления

    Откройте «О программе» и нажмите кнопку проверки обновлений.

  2. Скачайте новую версию

    При наличии обновления подтвердите скачивание и дождитесь завершения загрузки.

  3. Закройте DayZ

    Перед установкой новой версии выйдите из игры.

  4. Установите обновление

    Нажмите «Установить обновление». Companion закроется для установки новой версии.

  5. Дождитесь завершения

    Дождитесь автоматического запуска новой версии. Не выключайте компьютер и не запускайте Companion вручную во время установки.

В версии 1.7.0 STABLE отображается ход скачивания обновления, но после закрытия приложения отдельная индикация установки отсутствует. Даже если кажется, что ничего не происходит, дождитесь завершения: при успешном обновлении Companion самостоятельно запустит новую версию. Не выключайте компьютер и не открывайте приложение повторно во время установки.

Частые вопросы

Почему после запуска установки обновления окно исчезло?

Это нормальное поведение версии 1.7.0 STABLE. После скачивания приложение закрывается для установки файлов, а индикатор этого этапа пока отсутствует. Подождите автоматического запуска обновлённой версии. Если приложение долго не открывается, сообщите о проблеме через форму обратной связи.

Можно ли запускать приложение прямо из ZIP?

Сначала извлеките весь архив. Исполняемому файлу нужны соседние папки и файлы.

Что делать, если обновление не запускается?

Закройте DayZ и следуйте сообщению в Companion. Если проблема повторяется, сообщите о ней через Яндекс Форму.

Где сверить контрольную сумму?

Откройте сведения о релизе и найдите SHA-256 рядом с полным Windows ZIP.
