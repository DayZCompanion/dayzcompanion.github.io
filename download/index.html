Системные требования

  • Windows 10 или 11, 64-разрядная

    Для игровых инструментов нужна установленная игра DayZ.

  • Оконный режим DayZ

    Для полноценной работы всех инструментов используйте оконный режим игры. Безрамочный оконный режим рекомендуется для экранных наложений. В эксклюзивном полноэкранном режиме наложения могут быть скрыты, а захват изображения ограничен.

  • Место на диске

    Для ZIP и распакованных файлов вместе потребуется около 1 ГБ. Для обновления оставьте дополнительное свободное место.

  • Захват радио

    Для изоляции звука DayZ нужен поддерживаемый Windows WASAPI. На Windows 10 22H2 режим проверяется при запуске прослушивания.

Первый запуск

  1. Скачайте ZIP

    Нажмите «Скачать ZIP» в начале страницы.

  2. Распакуйте архив

    Извлеките все файлы в отдельную папку.

  3. Запустите DayZCompanion.exe

    Откройте файл в распакованной папке.

Обновление

В Companion откройте «О программе» и нажмите «Проверить обновления». После загрузки закройте DayZ и следуйте подсказкам приложения.

Частые вопросы

Можно ли запускать приложение прямо из ZIP?

Сначала извлеките весь архив. Исполняемому файлу нужны соседние папки и файлы.

Что делать, если обновление не запускается?

Закройте DayZ и следуйте сообщению в Companion. Если проблема повторяется, сообщите о ней через Яндекс Форму.

Где сверить контрольную сумму?

Откройте сведения о релизе и найдите SHA-256 рядом с полным Windows ZIP.
