System requirements

  • Windows 10 or 11, 64-bit

    Install DayZ to use the in-game tools.

  • Windowed DayZ

    Use windowed mode for full tool support. Borderless windowed mode is recommended for overlays. Exclusive fullscreen can hide overlays and limit screen capture.

  • Disk space

    Allow about 1 GB for the ZIP and extracted files together, plus extra free space for updates.

  • Radio capture

    Isolated DayZ audio capture requires Windows build 20348 or later. On Windows 10 22H2 (19045), compatibility is checked when listening starts.

First launch

  1. Download the ZIP

    Select “Download ZIP” at the top of this page.

  2. Extract the archive

    Extract every file into a separate folder.

  3. Run DayZCompanion.exe

    Open the executable from the extracted folder.

Updating

  1. Check for updates

    Open About and select the update check button.

  2. Download the new version

    If an update is available, confirm the download and wait for it to finish.

  3. Close DayZ

    Exit the game before installing the new version.

  4. Install the update

    Select Install update. Companion closes to install the new version.

  5. Wait for installation

    Wait for the new version to launch automatically. Do not turn off your computer or start Companion manually during installation.

Version 1.7.0 STABLE shows download progress, but there is no separate installation indicator after the app closes. Even if nothing appears to be happening, wait for installation to finish: after a successful update, Companion automatically launches the new version. Do not turn off your computer or reopen the app during installation.

Frequently asked questions

Why did the window disappear when I started installing an update?

This is normal behaviour in version 1.7.0 STABLE. After downloading the update, the app closes to install the files, and this stage does not yet show a progress indicator. Wait for the updated app to launch automatically. If it does not reopen after an extended wait, report the issue using the feedback form.

Can I run the app from inside the ZIP?

Extract the whole archive first. The executable needs the folders and files beside it.

What if the update does not start?

Close DayZ and follow the message in Companion. If the issue persists, use the Yandex form.

Where can I check the checksum?

Open the release details and find SHA-256 next to the full Windows ZIP.
