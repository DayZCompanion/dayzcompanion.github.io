About the project

DayZ Companion brings game tools together in a single Windows app. It is developed independently.

How Companion works with Windows and DayZ

The tools use different Windows features, so compatibility is checked tool by tool.

Windows and hotkeys

Configurable hotkeys control the tools. A separate on-screen HUD shows the decoder output.

Game audio

When Nasdara listening is active, the decoder processes audio from the DayZ process locally. How the decoder works.

Updates and external maps

Update checks connect to the release source. Companion opens XAM maps in its embedded browser without modifying their content. Map and feature availability depends on the service itself. Open the original site.

Development principles

Transparency

Each tool has its own requirements. Its page explains how it works.

Player control

Enable the tools you need and assign your own shortcuts.

Free access

A stable build is available for free. Donations are optional.

BattlEye

During our audit, we found no explicit prohibitions in BattlEye’s published materials on the DayZ Companion features we reviewed.

Official BattlEye FAQ

DayZ server rules

Each server sets its own rules. A server may restrict overlays or input automation. Read the rules before using Companion and ask the server administrators if anything is unclear.

Support development

The developer plays DayZ and makes Companion available for free. CloudTips is a way to support work on the app voluntarily.
