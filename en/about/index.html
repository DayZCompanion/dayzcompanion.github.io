About the project

DayZ Companion brings game tools together in a single Windows app. It is developed independently.

From individual tools to a control centre

Early releases offered separate tools, including the magnifier, gamma controls and earplugs. The Nasdara decoder, on-screen HUD and control centre came later.

Since 1.7.0 STABLE, all nine tools have shared an interface with settings and diagnostics.

How Companion works with Windows and DayZ

The tools use different Windows features, so compatibility is checked tool by tool.

  • Windows and hotkeys

    Configurable hotkeys control the tools. A separate on-screen HUD shows the decoder output.

  • Game audio

    When Nasdara listening is active, the decoder processes audio from the DayZ process locally. How the decoder works.

  • Updates and external pages

    The update check connects to the release source. Opening XAM takes you to a third-party service.
