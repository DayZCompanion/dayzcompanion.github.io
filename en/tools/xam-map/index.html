How to open a map

  1. Open the map

    While playing, press the default M hotkey if you have not changed it.

  2. Choose a map

    Select the world you are playing on.

  3. Adjust the display

    Filter the markers and landmarks you need.

Nasdara bunker map

The Morse decoder has a separate built-in map of 23 Nasdara bunkers. Known bunkers are highlighted automatically using received coordinates. This is distinct from the interactive XAM map.

Frequently asked questions

How does the map appear over the game?

A separate window with an embedded browser displays the XAM map alongside the Companion controls.

How do I find a bunker?

Double-click a Morse history entry to copy its coordinates and use the interactive XAM map search. The built-in bunker map in the Morse tool highlights known bunkers automatically.

Can I open a map without running the game?

Yes, open the map from DayZ Companion.

Who maintains XAM DayZ Map?

The XAM project maintains the service. Visit the original site. Internet access is required.

How do I close the map?

Press the assigned hotkey (M by default), Esc or the window’s close button.
