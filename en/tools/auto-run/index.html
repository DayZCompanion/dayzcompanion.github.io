Features

  • Holds the movement input

    Keep moving forward without holding the key down yourself.

  • Stops on command

    Use the assigned hotkey again to stop sustained movement.

Companion interface

Open the screenshot to take a closer look at the interface.

How to use Auto Run

  1. Open Auto Run

    Choose jog or sprint, then choose a hotkey or a double press of Shift as the activation method.

  2. Start moving

    Return to the focused game window and use your selected activation method.

  3. Stop moving

    Press W, A, S or D. If you started Auto Run with a toggle hotkey, you can press it again to stop.

How it works

  • Windows input

    Auto Run sends simulated keyboard input.

  • Control and rules

    Keep DayZ focused and check the server rules on input automation.

Frequently asked questions

Why is my character standing still?

Make sure DayZ has focus and check the in-game movement binding.

Does Auto Run choose a route?

You are responsible for steering and avoiding obstacles. Auto Run holds movement input.
