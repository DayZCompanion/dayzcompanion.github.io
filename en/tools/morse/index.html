Morse · Nasdara

Decode Nasdara’s digital radio transmissions. Companion captures audio from the DayZ process, recognises the signal and displays the coordinates and code over the game.

Download DayZ Companion

Recognises a digital signal

The decoder identifies short and long Nasdara radio tones and assembles the coordinates and PIN.

Shows results in-game

The HUD appears automatically when listening starts while DayZ is focused.

Keeps a transmission history

Complete transmissions are saved between launches. Selected records can be deleted.

Helps locate bunkers

The built-in map contains 23 Nasdara bunkers. A known bunker is highlighted automatically using the received coordinates.

How to set up

  1. Prepare the game

    Start DayZ, join a Nasdara server and tune the in-game radio to 80.0 MHz.

  2. Start listening

    Open the Morse Decoder in Companion. Start listening with the button or assigned hotkey.

  3. Check the result

    Wait for the transmission to finish. Read the coordinates and code in the app or HUD.

How the decoder works

DayZ audio → signal recognition → coordinates and code.

  • Audio source

    Windows WASAPI captures audio from the selected process. Decoding uses neither microphone input nor the mixed system audio.

  • Signal processing

    The decoder identifies short and long tones locally. A complete digital transmission contains six coordinate digits and a four-digit code.

  • Requirements

    DayZ must be running and audio capture must be supported: Windows build 20348 or later. On Windows 10 22H2 (19045), compatibility is checked when listening starts. Signal clarity affects the result.

Frequently asked questions

What if the decoder is not receiving a signal?

Check that Companion can see the DayZ process, listening is active and the in-game radio is tuned to 80.0 MHz. Look at the status in the decoder.

Where can I find an earlier transmission?

Open the log in Companion. It keeps complete decoded transmissions.

Which map can I use with the coordinates?

Known bunkers are highlighted automatically on the built-in map. Double-click a history entry to copy coordinates for searching the interactive map. More about maps.

Can I save a radio recording?

Yes. You can export up to the last three minutes of captured DayZ audio as a WAV file.
