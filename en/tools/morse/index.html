From signal to coordinates

Companion listens to audio from the DayZ process and shows the decoded result.

What the decoder does

  • Recognises a digital signal

    The decoder reads sequences of short and long tones and assembles the coordinates and code.

  • Shows results in-game

    The HUD displays the decoded result during gameplay. Complete transmissions are available in Companion’s log.

  • Helps you check coordinates

    Use the decoded coordinates with the map for your server.

How to receive a transmission

  1. Prepare the game

    Start DayZ, join a Nasdara server and tune the in-game radio to 80.0 MHz.

  2. Start listening

    Open the Morse Decoder in Companion. Start listening with the button or assigned hotkey.

  3. Check the result

    Wait for the transmission to finish. Read the coordinates and code in the app or HUD.

How the decoder works

DayZ audio → signal recognition → coordinates and code.

  • Audio source

    Windows WASAPI captures audio from the selected process. Decoding uses neither microphone input nor the mixed system audio.

  • Signal processing

    The decoder identifies short and long tones locally. A complete digital transmission contains six coordinate digits and a four-digit code.

  • Requirements

    A supported capture mode and a running DayZ process are required. On Windows 10 22H2, compatibility is checked when listening starts. Signal clarity affects the result.

Frequently asked questions

What if the decoder is not receiving a signal?

Check that Companion can see the DayZ process, listening is active and the in-game radio is tuned to 80.0 MHz. Look at the status in the decoder.

Where can I find an earlier transmission?

Open the log in Companion. It keeps complete decoded transmissions.

Which map can I use with the coordinates?

Check the map for your server. The maps page also describes Companion’s separate Nasdara bunker map.
