How to adjust gamma

  1. Open Gamma

    Select the tool in the control centre and enable the module.

  2. Adjust the setting

    Set gamma between 1.10 and 1.70 and check the preview.

  3. Apply correction in-game

    Return to the focused DayZ window and enable correction with the assigned hotkey.

Frequently asked questions

Why can’t I see a change?

The preview does not change system gamma. Enable correction with the assigned hotkey while DayZ is focused. If there is no effect, check the status message, HDR/SDR, graphics driver and game display mode.

What happens when I switch away from the game?

Companion restores the original gamma when DayZ loses focus. When you return, it automatically attempts to resume correction.

How does gamma work?

Companion uses Windows system gamma correction. This changes image midtones, not backlight brightness.
