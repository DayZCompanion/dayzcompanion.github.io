How to adjust gamma

  1. Open Gamma

    Select the tool in the control centre.

  2. Adjust the setting

    Change the value in small steps.

  3. Compare the image

    Check the result in the output mode you play in.

How it works

  • Windows display control

    Companion uses the system’s display gamma setting.

  • Output mode

    Support depends on the driver, monitor and output settings, including HDR.

Frequently asked questions

Why can’t I see a change?

Check the output mode and active monitor. Your driver or HDR settings may limit system gamma adjustments.

Does gamma change monitor brightness?

The monitor controls its backlight. Gamma changes how the image’s midtones are displayed.
