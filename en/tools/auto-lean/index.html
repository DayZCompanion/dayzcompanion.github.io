Auto Lean for DayZ

Automatically lean left or right when you strafe in DayZ.

Features

  • Links strafing to leaning

    In Auto Lean, A triggers Q and D triggers E. A and D together return to neutral.

  • Toggles with a hotkey

    Assign a hotkey to turn automatic leaning on and off.

Companion interface

Open the screenshot to take a closer look at the interface.

How to set up Auto Lean

  1. Check the game controls

    Check that A and D strafe, and Q and E lean, in DayZ.

  2. Set up Companion

    Open Auto Lean, enable the tool and assign its toggle key.

  3. Check it in DayZ

    Try both directions and turn the tool off again.

How it works

  • Keyboard input

    Companion sends the standard lean key inputs through Windows.

  • Game focus and rules

    Keep DayZ focused and check the server rules on input automation.

Frequently asked questions

Why does only one side work?

Check that the default DayZ bindings for strafing and leaning are active.

Can I still lean manually?

Yes. With Auto Lean off, use the regular game controls.
