Code Lock in DayZ Companion

Save your lock code in Companion and enter it with a single hotkey press. No need to type the same combination manually every time.

Download DayZ Companion

Saves your combination

Save a known numeric code of 1 to 6 digits.

Types the saved digits

Open the code entry field for your own lock in DayZ. Press the assigned hotkey to enter the saved digits followed by Enter.

Protected code storage

Your combination is encrypted locally using Windows DPAPI. You can temporarily reveal it in the settings.

How to set up

  1. Save your code

    Open Code Lock and enter your combination.

  2. Assign a hotkey

    Choose a shortcut that is free in the DayZ interface.

  3. Check the entry

    Open the input field for your lock and press the hotkey.

Frequently asked questions

How is the saved code protected?

The code is stored locally and protected by Windows DPAPI. You can briefly reveal it in the settings; it hides again after 15 seconds or when you leave the page.

How does the tool work?

With the lock’s code field open, Companion types your saved digits and automatically presses Enter.

What if the wrong code appears?

Check your saved digits and make sure the code field has focus. Check the server rules.

What happens if I switch away during code entry?

Automatic entry stops when DayZ loses focus.
