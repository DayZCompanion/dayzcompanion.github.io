Features

  • Saves your combination

    Enter a numeric code you already know in the tool settings.

  • Types the saved digits

    Use the shortcut once you have opened the code entry field for your lock in DayZ.

Companion interface

Open the screenshot to take a closer look at the interface.

How to set up Code Lock

  1. Save your code

    Open Code Lock and enter your combination.

  2. Assign a hotkey

    Choose a shortcut that is free in the DayZ interface.

  3. Check the entry

    Open the input field for your lock and press the hotkey.

How it works

  • Local storage

    Windows DPAPI protects the saved code in the user profile.

  • Input requirements

    Companion sends the digits as keyboard input. The code field must have focus. Check the server rules.

Frequently asked questions

Does Companion validate the combination?

The lock in the game checks it. Companion types the combination you saved.

What if the wrong code appears?

Check your saved digits and make sure the code field had focus.
