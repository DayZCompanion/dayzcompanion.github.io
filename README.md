# DayZ Companion — сайт (готов к публикации)

**Сборка:** 15 ноября 2026. Это отдельный статический сайт; исходники Windows-приложения здесь отсутствуют.

## Что внутри

- `index.html` — HTML и CSS сайта (работает без сборки).
- `assets/` — оптимизированные тематические изображения и три PNG-скриншота 1.7.0 TEST.
- `.nojekyll` — служебный файл для публикации на GitHub Pages без Jekyll.

## Открыть на любом ПК

Распакуйте ZIP полностью, а затем откройте `index.html` в браузере. Изображения находятся в `assets/` рядом с HTML, сетевое подключение не нужно для просмотра дизайна. Ссылки на GitHub, CloudTips и встроенная Яндекс Форма требуют интернет.

## Опубликовать бесплатно через GitHub Pages

1. Создайте **новый публичный репозиторий** в аккаунте `Surik115`, например `dayz-companion-site`. Не используйте приватный репозиторий приложения или репозиторий релизов.
2. Загрузите **содержимое этого ZIP** в корень нового репозитория: `index.html`, папку `assets`, `.nojekyll`, этот README. Не загружайте ZIP как единственный файл.
3. В репозитории перейдите **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветка `main`, папка `/(root)`, затем **Save**.
4. Дождитесь публикации и откройте ссылку из **Settings → Pages**. При имени репозитория `dayz-companion-site` адрес по умолчанию обычно `https://surik115.github.io/dayz-companion-site/`. Проверьте фактический адрес в настройках.
5. Проверьте мобильную страницу, кнопку скачивания STABLE, переход на CloudTips и загрузку Яндекс Формы.
