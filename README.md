# DayZ Companion Website 2.0

DayZ Companion — независимый набор инструментов для DayZ на Windows. Сайт состоит из 24 статических страниц на русском и английском языках. Публичный адрес — [dayz-mod.ru](https://dayz-mod.ru/).

## Сборка и локальный просмотр

Для сборки нужен Node.js 22+.

```powershell
node website/build.mjs
node website/preview.mjs 18170
```

Откройте [главную на русском](http://127.0.0.1:18170/) или [главную на английском](http://127.0.0.1:18170/en/). Команду предпросмотра запускайте в отдельном терминале. В другом терминале можно выполнить `node website/verify.mjs http://127.0.0.1:18170`.

Маршруты, тексты, общий HTML и реестр STABLE хранятся в `website/`. CSS, JS, изображения и иконки хранятся в `assets/`. Сборщик создаёт готовые HTML-страницы в корне и вложенных каталогах, а также sitemap и SEO-матрицу.
