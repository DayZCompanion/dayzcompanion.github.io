# DayZ Companion — официальный сайт

**Официальный адрес:** https://dayzcompanion.github.io/

Здесь хранится **полный исходный комплект публичного сайта**, его актуальные ресурсы и оригиналы тематических изображений. Сайт работает как статический HTML на GitHub Pages. Код Windows-приложения хранится в другом, приватном репозитории и здесь отсутствует.

## Где что находится

- `index.html` и `en/index.html` — русская и английская страницы. Обе используют `assets/site.css` и `assets/site.js`.
- `assets/hero.webp` — оптимизированный баннер на первом экране.
- `assets/tool-*.webp` — девять оптимизированных изображений карточек.
- `assets/ui-icons/*.svg` — девять унифицированных значков инструментов.
- `assets/dayz-logo.png` — **исходный пользовательский логотип 512×512** (внешний тёмный круг и белая центральная эмблема).
- `assets/dayz-logo-mark.png` — адаптация логотипа для шапки без лишнего внешнего кольца.
- `favicon.ico`, `assets/favicon-32.png`, `assets/favicon-64.png`, `assets/apple-touch-icon.png` — производные размеры фирменного значка.
- `assets/stable-*.png` — три скриншота DayZ Companion 1.7.0 STABLE.
- `design/source-images/` — десять **оригинальных PNG** до WebP-оптимизации: баннер и девять иллюстраций (не менять ради косметических правок CSS).
- `docs/SITE_GUIDE.md` — **основная инструкция**: дизайн, каталог ресурсов с SHA-256, сведения о версиях и безопасная публикация.

## Важные ограничения

- Обновляйте сайт в этом репозитории. Не заводите второй «главный» сайт и не храните утверждённые источники только в `Downloads`, временных папках или чатах.
- Не меняйте релизные ссылки, подписанный обновлятор, каналы TEST/STABLE и код приложения без отдельной задачи.
- Кнопки скачивания ведут на полный portable ZIP из [официального релиза v1.7.0](https://github.com/Surik115/dayz-companion-releases/releases/tag/v1.7.0).
- Не публикуйте секреты, внутренние файлы приложения, логи, обращения пользователей и другие персональные данные.
- Google Drive может использоваться как дополнительный резервный архив; первоисточник опубликованного сайта — этот репозиторий.

Подробности обслуживания и проверок: [`docs/SITE_GUIDE.md`](docs/SITE_GUIDE.md).


## Языки сайта

Русская версия доступна по адресу `/`, английская — по `/en/`. Ссылки в шапке ведут на соответствующую страницу. Текст и описания изображений редактируются в HTML каждой версии. Подробности в `docs/SITE_GUIDE.md`.

### Мобильные карточки (исправление 16.11.2026)

Устранено залипание раскрытия при повторном нажатии. На телефоне длинные тексты прокручиваются вместе со страницей; фокус на кнопке больше не удерживает карточку раскрытой.

### Следующие локализационные шаги

Английские скриншоты приложения и англоязычная форма обратной связи пока **не реализованы**. Задачи и критерии описаны в `docs/SITE_GUIDE.md`. Внешняя Яндекс Форма пока доступна на русском; в английской версии сайта это указано.
